# 夜幕之下抽卡记录导出

一个面向 Windows 版《夜幕之下》的本地契约记录捕获与导出工具。

它使用 Windows 自带的 `pktmon` 被动读取游戏已返回给客户端的抽卡历史，不注入游戏进程，不读取账号密码，也不向第三方服务器上传数据。记录保存在本机，可导出为 JSON 或 CSV。

> 当前处于早期协议验证阶段。游戏更新后，协议命令或字段语义可能变化。

## 使用方式

1. 启动游戏并登录。
2. 打开本工具，点击“开始捕获”，在 UAC 窗口中允许管理员权限。
3. 在游戏中进入“契约记录”，点击“全部记录”。
4. 把鼠标停在右侧的“下一页”箭头上，按 `F8`。
5. 工具会自动翻完页面、停止捕获并合并本地记录。
6. 使用右上角按钮导出 JSON 或 CSV。

自动翻页时不要移动鼠标或切换窗口。管理员权限只用于启动和停止 Windows 内置的 `pktmon`；捕获结束后筛选器会被移除。

## 数据与隐私

- 本地数据保存在 Electron 的应用数据目录中。
- 仓库不会收集或包含登录令牌、Cookie、设备标识、原始网络包或个人抽卡数据。
- `.gitignore` 排除 `*.etl`、`*.pcapng`、日志、导出目录与 `.env` 文件。
- 若要提交问题，请先删除截图和日志中的账号信息。

## 开发

需要 Node.js 20 或更新版本。

```bash
npm install
npm test
npm run lint
npm run start
```

构建 Windows zip：

```bash
npm run build:win
```

## 已确认的协议

- 游戏主连接：TCP `12090`
- 历史命令：`0x000c08`
- 请求字段：卡池 ID、从 0 开始的页码
- 响应字段：筛选卡池、总记录数、每页 5 条记录
- 单条记录：实际卡池 ID、结果 ID、毫秒时间戳

“全部记录”的卡池 ID 为 `0`。当前版本通过本地 UI 自动翻页获取完整 90 天历史，并使用“卡池 + 结果 + 时间 + 同值序号”保留十连中同毫秒出现的重复结果。

结果名称由游戏本地配置解析，首版协议层先保存稳定的内部 ID；名称映射会以可更新的数据文件补充，原始 ID 永远保留。
